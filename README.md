🤖 Pallavi AI – Voice Enabled Chat Assistant

Pallavi AI is a full-stack AI chat application built with React (Vite) and FastAPI.
It features a WhatsApp-style UI, dark mode, AI replies, and female voice text-to-speech support.

🚀 Live Demo

Backend: https://pallavi-ai-backend.onrender.com

Frontend: (https://pallavi-ai-project.vercel.app/)

✨ Features

💬 AI-powered chat

🗣️ Female voice (Text-to-Speech)

🌙 Dark mode

📱 Mobile & desktop friendly

🧑‍🎨 AI avatar

⚡ Fast & lightweight

🛠 Tech Stack

Frontend: React (Vite), CSS, Web Speech API
Backend: FastAPI, Python
Deployment: Vercel (Frontend), Render (Backend)
